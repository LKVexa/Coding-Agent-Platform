# Implementation report

This release implements a local coding-agent workflow for one committed Python numeric function. A real model returns a full-file proposal. The host checks its path and baseline hash, evaluates disclosed examples, and permits at most one correction using that public feedback. It then runs separately frozen private cases once, preserves failing-to-passing and passing-to-passing outcomes, reconstructs a unified patch, and exports only accepted changes.

The candidate has no process, filesystem, network or credential APIs: a small AST interpreter handles numeric expressions and bounded control flow. The model provider is a separately trusted authenticated CLI with an independently captured empty tool registry. It retains built-in model guidance and may inherit global Codex guidance; this is not an operating-system container or a guarantee that every provider instruction comes from the task.

The original repository is read through Git blob plumbing, with no checkout, filters, repository programs or dependency installation. A one-file source snapshot and candidate tree live in separate state. Interrupted provider call intents are never reissued by resume. Completed runs have file receipts; export replays the patch and evaluation before producing a review folder.

The foundation is embedded unchanged at its verified manifest pin. The platform directly uses its strict JSON/schema, path, hash, evidence and locking utilities, loads its historical component registry, and provides a D0007 correct/regression diagnostic command. The platform-specific evaluator and provider are new implementations. Other source candidates remain historical/catalog-only; no training, paper reproduction, arbitrary repository testing or automatic deployment was added.

Independent review found and repaired four workflow defects: late cancellation could invalidate receipts; the first control-lock repair failed under contention; partial terminal recovery could reseal unchecked results; and Git commondir could redirect source identity. The acceptance evidence retains those findings and the passing regression checks. Provider discovery also exposed inherited global guidance; that limitation is recorded explicitly rather than represented as pure prompt isolation.

The complete local state includes private diagnostic outcomes for inspection. Patch exports omit private case values. Packaged authored diagnostic cases are non-secret fixtures withheld from model context; they are not private customer data. Source and public task text are transmitted to the configured provider. There is no automatic secret scanner for user-selected source.

Consult the outer release acceptance report and gate files for the exact tested package and real task outcomes. This implementation report makes no general coding-performance claim.
