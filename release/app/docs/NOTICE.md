This package is prepared locally for the user who supplied D0001–D0008. It does not publish those deliveries or grant rights over third-party source material. The embedded foundation preserves its own provenance, historical status and original evidence.

The new platform, bounded evaluator, task fixtures, contracts and documentation were authored for this task. Python, Git, Windows and the authenticated Codex executable are required local runtimes, not bundled executables. The no-tools model catalog is derived from the installed Codex runtime catalog and pinned as configuration data. It contains model metadata and generic instructions, not credentials.

The provider interface and authentication behavior were checked against the installed runtime and the official [non-interactive documentation](https://learn.chatgpt.com/docs/non-interactive-mode) and [authentication documentation](https://learn.chatgpt.com/docs/auth). Actual behavior is supported by local capture, identity and execution evidence. No API prices or remote serving identity are inferred.

No credential file, authentication token, customer private task set or unrelated workspace is included in the release. The supplied example checks and authored diagnostic evaluations are intentionally inspectable local fixture data.
