# Numeric Utilities Demonstration Repository

This small authored repository supplies local coding-agent tasks. It is a real
repository template with intentionally faulty pure functions; it is not a public
benchmark or a reproduction of the original research deliveries. Initialize it
with Git before running a task, then work only on isolated snapshots.

The supported language profile is one numeric pure function per module. Functions
may use local assignment, `if`, `return`, arithmetic, comparisons, boolean and
conditional expressions, and `min`, `max`, `abs`, or `int`. Imports, attributes,
filesystem/network access, loops, recursion, containers, and arbitrary calls are
outside this initial release. The evaluator interprets permitted syntax; it never
imports or executes candidate Python code.

Task descriptions are supplied separately. Preserve the declared function name
and parameter names and edit only the task's allowlisted source file.
